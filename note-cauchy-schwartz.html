Cauchy-Schwartz Inequality

2025-10-28 数学 知乎原文

这是一篇库存，也没啥内容，就证了个柯西洗袜子，写都写了传一个备份吧

$(H,\braket{·,·})$ is a vector space over $\mathbb{K}\in\{\mathbb{R},\mathbb{C}\}$ with inner product. Then $\forall x,y\in H$, we have:

$$|\braket{x,y}|^2\le\braket{x,x}·\braket{y,y}$$

Pf: Let $t\in\mathbb{R}$, then

$$\braket{x+ty,x+ty}=\braket{x,x}-t\braket{x,y}-t\braket{y,x}+t^2\braket{y,y} \newline =\braket{x,x}-2t Re\braket{x,y}+t^2\braket{y,y}\ge0$$

When we take t as variant, this is a quadratic polynomial inequality. Consider the relevant discriminant constrain:

$$\begin{equation} |2Re\langle x,y\rangle |^2\le4\langle x,x\rangle\langle y,y\rangle\Rightarrow |Re\langle x,y\rangle |^2\le\langle x,x\rangle\langle y,y\rangle \end{equation}~~~~~~~~~~~~(1)$$

Now we define function $\overline{sgn}:\mathbb{C}\to\mathbb{C},~~\rho e^{i\theta}\mapsto e^{-i\theta}$, take $\tilde{y}=\overline{sgn(\braket{x,y})}y$, then we have

$$|\braket{x,\tilde{y}}|^2=|\overline{sgn(\braket{x,y})}\braket{x,y}|^2$$

Notice that $\overline{sgn(\rho e^{i\theta})}\rho e^{i\theta}=\rho\in\mathbb{R}$, which is the modular of the variable, so it is consistent with $|·|^2$:

$$|\braket{x,\tilde{y}}|^2=|\overline{sgn(\braket{x,y})}\braket{x,y}|^2=|\braket{x,y}|^2~~~~~~~~~~~(2)$$

On the other hand, $\braket{x,\tilde{y}}\in\mathbb{R}$, so

$$|\braket{x,\tilde{y}}|^2=|Re\braket{x,\tilde{y}}|^2$$

Use eq. (1), we have

$$|\braket{x,\tilde{y}}|^2=|Re\braket{x,\tilde{y}}|^2\le\braket{x,x}\braket{\tilde y,\tilde y}=\braket{x,x}\overline{sgn(\braket{x,y})}sgn(\braket{x,y})\braket{y,y}=\braket{x,x}\braket{y,y}$$

Combine this with eq. (2), we obtain:

$$|\braket{x,y}|^2\le\braket{x,x}\braket{y,y}$$ $\boxed{}$
